CODEX PROTOCOL / 01

One stable address.
A shared visual vocabulary.

Give Codex the manifest, describe the page goal, and ask it to select only the models, recipes, image assets, and motion sources that earn their place.

01 / DISCOVER

Start with the manifest

https://lumoraofficial.de/mcp/manifest.json
02 / SELECT

Use a precise Codex brief

“Read the Lumora MCP manifest. Choose up to two components, one ship-safe 3D model, up to three image or UI assets whose style and usage mode fit the project, and at most one commercially licensed animated background. Compare style guidance, rights, and performance before implementing.”

03 / IMPLEMENT

Fetch only what wins

const manifest = await fetch(
  "https://lumoraofficial.de/mcp/manifest.json"
).then(response => response.json());

const models = await fetch(
  manifest.endpoints.models
).then(response => response.json());

const images = await fetch(
  manifest.endpoints.imageAssets
).then(response => response.json());

const backgrounds = await fetch(
  manifest.endpoints.animatedBackgrounds
).then(response => response.json());
04 / PROVE

Keep provenance intact

Models and image assets retain creator, source, licence, package metrics, and warnings. Component recipes retain their accessibility, fallback, responsive, performance, and testing contracts. Background records retain their source URLs and Lumora commercial-use entitlement.
