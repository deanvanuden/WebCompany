# Lumora Website

Statische Website für Lumoras aktuelle Nachfragevalidierung. Sie erklärt den geplanten Website-Sprint für lokale Dienstleister, zeigt vier vollständig selbst umgesetzte Projekte und bietet einen unverbindlichen Kontaktweg. `index.html` kann direkt im Browser geöffnet werden.

## Dateien

- `index.html` - Positionierung, geplanter Leistungsumfang, Projektlinks, Ablauf, Team und unverbindlicher Kontakt.
- `styles.css` - visuelles System, responsive Layouts, Reveal-Zustände und Galerie-Previews.
- `script.js` - mobiles Menü, magnetische Buttons, Reveal-Zustände und Galerie-Steuerung.
- `impressum.html` - Anbieterinformationen und Kontaktangaben.
- `datenschutz.html` - Datenschutzhinweise zum Hosting und zur Kontaktaufnahme.
- `assets/projects/` - Screenshots der selbst umgesetzten Websites in der Projektgalerie.
- `assets/approach/` - generierte visuelle Elemente für Strategie, Interface, Motion und Launch.
- `assets/studio-poster.png` - generiertes Fallback- und Social-Preview-Bild.
- `assets/LogoLumora.png` - Favicon-Bild.

## Hinweis

Die Seite ist auf Deutsch, als Lumora gebrandet und nutzt `lumoraofficialde@gmail.com` für Kontakt-Mailto-Links. Sie lädt keine externen Schriftarten, Analyse- oder Werbedienste.
